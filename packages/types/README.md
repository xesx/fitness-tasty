# @fitness-tasty/types

Общие TypeScript-типы и DTO, которыми обмениваются `backend-api` и его
клиенты (фронтенды, `backend-bot`, `backend-cli`, `backend-cron`). Пока
не создано — это заготовка пакета, которая резервирует место в
workspace.

Цель — исключить дублирование типов данных между бэкендом и всеми его
потребителями.
